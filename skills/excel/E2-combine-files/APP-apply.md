# Uygulama — E2 Çoklu Dosya Birleştirme

1. **Data** > **Get Data** > **From File** > **From Folder** → klasör seç.
2. Power Query önizleme: tüm dosyalar listelenir → **Combine** > **Combine & Transform Data**.
3. Sütunları hizala (Power Query otomatik eşler; farklıysa `Merge Columns`/`Reorder`).
4. `Close & Load` → Master sheet.
5. Yeni dosya eklenince: **Data** > **Refresh All**.

## İpucu
- Dosya isimlendirmesi: `Bolge_2026-08.xlsx` gibi standart olsun.
- Sütun eklenirse Power Query hata verir (sessiz yanlış veri yok) → prompt doğru.
