# Uygulama — C6 Whiteboard

1. Whiteboard aç (web/Teams/uygulama).
2. **Templates** → Sprint / Brainstorm / Retrospective şablonu seç.
3. **Note** (sticky) ekle; katılımcılar aynı anda yazsın.
4. **Share** (sağ üst) → link kopyala, dış katılımcıya gönder (toplantı içi/dışı).
5. Bitince **Settings** → **Export to image** (PNG) → kaydet.

> M365 ile ücretsiz; Surface/dijital kalem için optimize.
