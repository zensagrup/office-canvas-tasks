# Uygulama — C4 Şablon Kütüphanesi

1. **Brand Kit** kur: renk, font, logo (Settings → Brand Kit).
2. 1–2 versiyon şablon tasarla: Quote card, Carousel slide, Thumbnail, Cover.
3. Şablonu aç → **···** → **Set as Template** → **Publish** → Brand bölümüne düşer.
4. "Creator Templates" klasörü aç, hepsini oraya koy.
5. Yeni içerikte: şablonu **Duplicate** et, içeriği değiştir, yayınla.

> 100 şablon değil; 5–10 gerçekten kullandığın şablon yeter.
