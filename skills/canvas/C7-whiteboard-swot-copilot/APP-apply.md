# Uygulama — C7 Whiteboard SWOT + Copilot

1. Whiteboard > **Templates** → **SWOT Analysis** şablonu.
2. Dört kadra nota ekle (Strengths/Weaknesses/Opportunities/Threats).
3. **Copilot** (Whiboard içinde) → *"Summarize this SWOT into action items."*
4. Copilot görev listesi üretir (örn. "SEO focus, web redesign").
5. **Loop component** olarak paylaş → Teams/Word senkron.

> Copilot notları "okur", göreve çevirir; son karar insanında.
