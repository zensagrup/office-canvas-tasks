# Uygulama — W3 Etiket / Zarf

1. **Mailings** > **Start Mail Merge** → **Labels** (veya **Envelopes**).
2. Etiket tedarikçisi/kodu seç (örn. Avery 5160).
3. **Select Recipients** → Excel/Outlook.
4. **Insert Merge Field** → Adres bloklarını yerleştir.
5. **Update Labels** (tüm etiketlere yay).
6. **Preview** → **Finish & Merge** → belgeye veya doğrudan yazıcıya.
