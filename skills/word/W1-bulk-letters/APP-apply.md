# Uygulama — W1 Toplu Mektup (Mail Merge)

1. Word'de boş belge → **Mailings** sekmesi → **Start Mail Merge** → **Letters**.
2. **Select Recipients** → **Use an Existing List** → Excel dosyasını seç.
3. İmleci metne koy → **Insert Merge Field** → `First_Name`, `Company` vb. ekle.
   Örnek: `Sayın «First_Name», ...`
4. **Preview Results** ile bak; ilk 5 kaydı kontrol et.
5. **Finish & Merge** → **Edit Individual Documents** → All → yeni belge (her kayıt ayrı sayfa).
6. **Uyarılar:** Excel başlıklarında boşluk/özel karakter olmasın; formül hücresi kullanma, düz metin olsun.

> Hata olursa: veri kaynağını kapat, başlık satırını düzelt, yeniden bağla.
